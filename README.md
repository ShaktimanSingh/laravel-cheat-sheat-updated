# Laravel Artisan Cheat Sheet Updated

🎯 A complete and beautifully formatted cheat sheet of Laravel Artisan commands — structured, categorized, and future-proof. Ideal for developers at all levels who want quick access to essential Artisan CLI commands used across Laravel projects.

---

## 📦 What's Included

- ✅ Project management commands
- ✅ Database & migration tools
- ✅ Authentication & authorization generators
- ✅ Testing commands (unit, feature, browser)
- ✅ Deployment helpers
- ✅ Code scaffolding (models, controllers, events, policies, etc.)
- ✅ Caching tools
- ✅ Package and queue management
- ✅ Extra commands for maintenance, optimization, and debugging

---

## 📚 How to Use

Clone or download this repo and open the `laravel-artisan-cheatsheet.md` file in your preferred Markdown viewer or IDE.

```bash
git clone https://github.com/YOUR_USERNAME/laravel-artisan-cheatsheet.git
cd laravel-artisan-cheatsheet
```
